## 📌 Introduction

Data visualization is an essential part of data analysis. Basic charts help in understanding patterns, trends, and relationships in data, while visual encoding defines how data values are represented visually.

These techniques include:

-   Creating basic charts (bar, line, pie, histogram)
-   Using colors, shapes, and sizes for encoding
-   Labeling axes and titles
-   Customizing chart appearance
-   Representing data clearly and effectively

Python provides libraries like Matplotlib and Seaborn for creating visualizations.

## ❌ Disadvantages
